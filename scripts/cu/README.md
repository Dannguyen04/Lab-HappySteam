# Script cũ (dùng một lần)

Các script đã sinh dữ liệu 3D cho những bài làm trước khi có `scripts/new-lesson.js` và `scripts/rbb2content.js`.
Kết quả của chúng đã nằm trong `content/`. Giữ lại để tham khảo hoặc khi cần sinh lại đúng bài đó; chạy từ gốc dự án, ví dụ `node scripts/cu/generate-bai03.js`.
